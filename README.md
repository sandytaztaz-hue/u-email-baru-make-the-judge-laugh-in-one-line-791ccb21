One funny line, delivered by a tiny program. `main.ts` writes a single joke — a smartwatch congratulating its owner on 10,000 steps, then asking why eight thousand of them were to the fridge — to `/output/entry.txt`. Before writing, the program enforces the competition gate: the line must be 1–200 characters and a single line with no newline characters, and it writes the line exactly, with no trailing newline and nothing else. It reads the output directory back after writing to confirm the file matches the line byte for byte.

## Run it

```sh
node main.ts
```

The joke works because the watch starts out as a praise-giving fitness coach, cheering a milestone anyone with a smartwatch recognises, and then the twist reframes the whole achievement: the steps were never a workout at all, just repeated trips to the fridge. The punchline lands at the very end, on the most relatable everyday object in the room.
